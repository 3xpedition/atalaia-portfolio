O produto

Dois olhares.
Uma mesma jornada.

O Atalaia estrutura o ciclo e os processos. O Gavião transforma esse conjunto em visão gerencial, acompanhamento e ação móvel. Juntos, eliminam ilhas de informação sem simplificar demais a realidade.

01

Atalaia

Estrutura para acompanhar cada etapa.

Organiza ciclos, grupos, avaliações, situações e relatórios em fluxos consistentes, com permissões e regras aplicadas no servidor.

  • Gestão de ciclos e participantes
  • Avaliação e consolidação
  • Relatórios rastreáveis
02

Gavião

Contexto para decidir com confiança.

Conecta indicadores, registros de acompanhamento e operação móvel para revelar tendências sem perder o caminho até a origem do dado.

  • Painéis e séries comparáveis
  • Registros em campo
  • Operação online e offline

Demonstração · sem dados reais

Offline não é um erro.
É um estado do produto.

O aplicativo carrega os dados necessários, protege a sessão local e cria registros com identidade única. Quando a rede retorna, a fila sincroniza sem duplicar o que já chegou ao servidor.

  • armazenamento local protegido
  • reenvio com espera progressiva
  • estado visível para o usuário
  • autorização novamente validada no servidor

Segurança

O servidor decide.

Filtros na interface ajudam o uso; autorização em todos os endpoints protege o dado.

Consistência

Uma regra, várias saídas.

Painel, exportação e relatório partem da mesma lógica de domínio.

Resiliência

A rede pode falhar.

Fila local, idempotência e retentativas mantêm o fluxo previsível.

Privacidade

Somente o necessário.

Dados mínimos, cache controlado, logs sem conteúdo sensível e chaves protegidas.

EnvioRegistroWorker.kt
for (registro in fila.pendentes()) {
    val resposta = api.enviar(
        registro.idUnico,
        registro.paraEnvio()
    )

    when {
        resposta.sucesso -> fila.concluir(registro)
        resposta.transitorio -> retry()
        else -> fila.revisar(registro)
    }
}
