O que observar

Cada regra existe por causa de um erro real.

  • Zero não é ausênciaTratar nota não lançada como zero inventa alunos críticos que ninguém avaliou.
  • Total que fechaUm reintegrado contado no ciclo errado basta para o painel divergir do número oficial.
  • Escala honestaFaixas iguais pintam quase o país inteiro de uma cor só quando um estado dispara.
  • Reenvio seguroSem identificador único, a rede que cai no meio do envio duplica o registro disciplinar.

Escopo seguro

Demonstração, não reprodução.

Nenhum arquivo foi copiado do repositório institucional. Não há dados reais, credenciais, nomes de bancos, endereços internos ou estruturas privadas nesta coleção.

Todos os exemplos são autorais e sanitizados, escritos a partir das regras reais do sistema.
