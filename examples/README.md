# Exemplos de código

Exemplos autorais criados para demonstrar organização e práticas de engenharia em um domínio educacional fictício.

- [`controllers/IndicadorController.php`](controllers/IndicadorController.php): validação de filtros e resposta HTTP.
- [`models/IndicadorAcademico.php`](models/IndicadorAcademico.php): modelo Eloquent com escopo de período.
- [`services/ConsolidaIndicadoresService.php`](services/ConsolidaIndicadoresService.php): agregação e transformação de dados.
- [`sql/resumo_avaliacoes.sql`](sql/resumo_avaliacoes.sql): consulta agregada sobre tabelas fictícias.
- [`views/painel-indicadores.blade.php`](views/painel-indicadores.blade.php): apresentação acessível e responsiva.

Nenhum exemplo depende do banco, das classes ou das regras do sistema institucional.
